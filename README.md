# 응용 - 스프링부트+리액트 웹앱

1. 프로젝트 설정
	1. 프레임워크는 스프링 부트 사용
	2. 톰캣 등 별도의 WAS 사용 상정
		1. 개발상태에서
			1. localhost - 스프링 부트 웹앱 서버(:8080)와 리액트 서버(:3000) 별도로 실행
			2. 웹앱 서버에 접속하면 리액트 서버의 index.html로 포워딩
			3. 이후 웹앱 서버는 api서버로만 동작
			4. 클라이언트 요청시 웹앱서버로 proxy
		2. 배포환경에서
			1. 리액트 빌드 결과물을 웹앱 프로젝트의 static 이하 경로에 배치
